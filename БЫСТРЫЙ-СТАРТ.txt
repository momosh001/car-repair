ЖУРНАЛ РЕМОНТА АВТО — КАК ПОЛЬЗОВАТЬСЯ
=====================================

ФАЙЛЫ
-----
remont-avto.html          — само приложение (открывается в браузере, интернет не нужен)
shablon-google-tablicy.csv — заготовка таблицы для Google Таблиц / Excel
БЫСТРЫЙ-СТАРТ.txt          — этот файл


КАК ПЕРЕНЕСТИ НА ТЕЛЕФОН (3 минуты)
----------------------------------
Вариант 1. Мессенджер (проще всего)
  1. Отправьте файл remont-avto.html себе в Telegram «Избранное» (или на почту).
  2. На телефоне откройте сообщение и нажмите на файл.
  3. Выберите «Открыть в браузере» / «Chrome» / «Safari».
  4. Меню браузера → «Добавить на главный экран». Готово — будет иконка как у приложения.

Вариант 2. Через кабель / облако
  Скиньте файл в память телефона (Google Drive, кабель, Bluetooth),
  затем откройте его через приложение «Файлы» → «Открыть с помощью» → браузер.


КАК РАБОТАТЬ
------------
• Вкладка «Новая запись»: VIN, что ремонтировали, стоимость, фото, дата (ставится сама).
  Если VIN уже вводили раньше — марка, номер и клиент подставятся автоматически.
• Фото: кнопка «📷 Добавить фото» (камера или галерея), до 6 на запись.
  Нажмите на миниатюру в истории — фото откроется на весь экран.
• Вкладка «История»: все ремонты. Введите VIN в поиск — увидите всю историю
  этой машины и общую сумму по ней.
• Вкладка «Клиенты»: собирается сама по имени и телефону. Внутри карточки —
  машины клиента, все ремонты, общая сумма и кнопка «Позвонить».
• Нажмите на запись — откроется для исправления. Внутри есть «Удалить».


ГДЕ ХРАНЯТСЯ ДАННЫЕ
-------------------
Это обычная HTML-страница, которая открывается в браузере телефона (Chrome / Safari).
Никакого сервера и аккаунта нет: записи и фото лежат в памяти браузера на самом телефоне
(записи — в localStorage, фото — в IndexedDB). Интернет не нужен, данные никуда не уходят.
Хотите синхронизацию между устройствами — выгружайте CSV в Google Таблицы или носите
JSON-копию вручную.


ВАЖНО
-----
Записи и фото хранятся в памяти браузера ТОЛЬКО этого телефона.
• Не очищайте «Данные сайтов» в браузере.
• Раз в неделю: «История» → «Сохранить / выгрузить» → «Резервная копия (JSON)».
  Фото входят в копию. Отправьте файл себе в мессенджер.
  При смене телефона: там же «Восстановить из копии» → выбрать файл.


КАК ЗАЛИТЬ В GOOGLE ТАБЛИЦЫ
---------------------------
Из приложения: «История» → «Скачать таблицу (CSV)» → файл открыть в Google Таблицах
(или drive.google.com → «Создать» → «Загрузить файл» → правой кнопкой → «Открыть с помощью Google Таблиц»).

Либо сразу вести в Google: загрузите shablon-google-tablicy.csv на drive.google.com,
откройте как Google Таблицу — колонки уже готовы.


УСТАНОВКА "ПО-ВЗРОСЛОМУ" (необязательно)
----------------------------------------
Чтобы приложение работало как полноценная иконка с офлайн-режимом, файл нужно
разместить на любом бесплатном хостинге (например, GitHub Pages, Netlify Drop)
и открыть ссылку на телефоне → «Добавить на главный экран».
